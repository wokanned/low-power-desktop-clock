# GDEY029T94-FL03 显示移植记录

## 范围与来源

目标屏幕为 GDEY029T94-FL03，控制器 SSD1680Z8，横向显示 296×128，无触摸。本轮把已测试参考工程接入 DeskClock 的 STM32L471RET6 + FreeRTOS 基础工程，复用其驱动、GUI、字库、图像资源和时钟刷新策略。参考工程通过测试不代表本板已经通过验证。

固定参考版本为 `origin/EinKTest@8583f09f19f494ca43bf29635b3a4e1d170922bf`，源码位于该版本的 `elinkTest/`。使用提交哈希确认版本，不能仅依赖后续可能移动的分支名。

硬件连接依据同一版本中的两份网表：

- 主板：`Netlist_Schematic2_2026-05-21.tel`。
- 显示转接板：`墨水屏驱动板网表2026-09-28.tel`。

这些资料与 `Core/Inc/main.h`、`Core/Src/spi.c` 和 `Core/Src/gpio.c` 交叉核对。当前墨水屏供电已改为持续上电，历史网表中的显示负载开关连接不再适用。移出工作区的主板网表不恢复到仓库。尚未确认现有实物板与该版本网表完全一致，上板前需要核对板版本和实际接线。

## 模块职责与调用入口

| 模块 | 职责 | 边界 |
| :--- | :--- | :--- |
| `device/epd_gdey029t94` | SSD1680Z8 协议、初始化、BUSY 超时、刷新、背景缓存和统计 | 无 HAL 依赖，所有硬件访问通过注入的 IO 回调 |
| `platform/stm32_gdey029t94` | 绑定 SPI2、CS/DC/RES/BUSY 与延时 | HAL 和板级资源集中于此，SPI 同步发送并有超时 |
| `gui/GUI_Paint` | 原厂绘图与全局 Paint 画布 | 保留参考接口，由显示任务独占 |
| `fonts/`、`resources/` | 原厂西文/中文字库与演示图像 | 保留参考数据，不任意改协议、字模或图像编码 |
| `app/epd_clock_view` | 四灰阶页面和保留的黑白诊断绘制 | 读取不可变模型，绘图与传输分开 |
| `app/epd_bringup` | 分钟/故障全刷调度、可选演示编排和状态统计 | 调用 device/platform 公开能力，不直接操作 SPI/GPIO |
| `app/clock_service`、`clock_faults` | RTC/内存快照和七类故障聚合 | defaultTask 定时采集，生产者报告实际故障 |
| `app/display` | 创建唯一显示任务，处理有限重试、日志与最终挂起 | 独占控制器、帧缓冲、刷新状态和 Paint |
| `Core/Src/freertos.c` | RTOS 对象初始化时调用 `display_start()` | Core 保留系统接入入口，业务留在 app |

公开入口为 `display_start()` 和 `display_get_last_status()`。`epd_bringup_run_clock()`、`epd_bringup_run_once()` 及 `epd_bringup_get_last_status()` 保留参考能力，但刷新和绘图只能从唯一显示任务调用。其他任务或 ISR 不得直接调用驱动、操作 Paint 或访问 SPI2。未来若增加显示请求，需要先建立串行请求接口，不能直接增加调用者。

## 主板 GPIO 与连接器

U1 为 STM32L471RET6，LQFP-64。主板连接器为 H8，转接板输入连接器为 H1。

| 信号 | MCU GPIO / 资源 | U1 物理脚 | 主板 H8 | 转接板 H1 |
| :--- | :--- | :---: | :---: | :---: |
| GND | GND | — | 1 | 1 |
| BUSY | PC5，输入，高有效 | 25 | 2 | 2 |
| RES | PB0，复位低有效 | 26 | 3 | 3 |
| D/C | PB1，输出 | 27 | 4 | 4 |
| CS | PB2，输出 | 28 | 5 | 5 |
| MOSI / SDI | PC3，SPI2 AF5 | 11 | 6 | 7 |
| SCK / SCLK | PB10，SPI2 AF5 | 29 | 7 | 6 |
| 显示供电 | 系统 3.3V，持续供电 | — | 8 | 8 |

**数据与时钟两线必须交叉：H8.6→H1.7，H8.7→H1.6。** 主板和转接板的 6、7 针信号顺序相反，不能使用这两针相同针号直通的接法。其余针位按表连接。不要为了迁就直通线而交换 MCU 的 MOSI/SCK 功能。

PC2 的 SPI2 MISO 仍保留既有配置，但主板显示接口未接该信号；当前驱动只发送，不依赖 MISO。I2C2 的实际引脚为 PB13=SCL、PB11=SDA，与本显示 SPI2 的 PB10 不冲突。

## 供电与前置光边界

墨水屏在系统供电期间持续上电，显示负载开关已移除。初始化、错误恢复、任务挂起和整机休眠均保持显示供电。上板时核对实际供电接线和电压，续航评估应计入屏幕待机电流。

平台已移除旧的 `ELINKEN` 绑定、GPIO 写入和供电等待，初始化仅准备 CS/DC/RES。Core 中的历史 GPIO 定义不作为屏幕供电控制使用。既有构建和测试记录不能用于证明硬件变更后的板上行为。

转接板网表可见前置光 FPC 和电阻到供电/GND 的连接，但未建立独立 MCU 前置光开关或调光引脚。当前移植不新增 PWM 或猜测控制脚，前置光控制、电流和功耗仍待确认。

## SPI、延时与 RTC

- SPI2 使用 PC3 MOSI、PB10 SCK，AF5。预分频设为 32，当前 80MHz 外设时钟得到 2.5MHz；`DeskClock.ioc` 和 `Core/Src/spi.c` 保持同步。
- 平台使用同步 `HAL_SPI_Transmit`，不在本轮引入 DMA。调用期间由显示任务持有总线与命令状态，传输长度和超时有界。
- 调度器运行且处于任务上下文时，平台毫秒延时转换为 RTOS tick 并调用 `osDelay`，BUSY 轮询不会持续占用 CPU。调度器启动前使用 HAL 延时。显示接口不允许从 ISR 调用。
- HAL 毫秒时间来自 TIM17，FreeRTOS 内核 tick 使用 SysTick，沿用基础工程的时基分工。
- RTC 读时间后继续读日期以释放影子寄存器锁，并校验时分秒范围。
- `Core/Src/rtc.c` 使用 `RTC_BKP_DR0` 的 `0x52544331` 初始化标记。标记有效时跳过默认日期、时间和闹钟重置；备份域丢失后重新初始化。每次启动都恢复 ALARM EXTI 中断及上升沿触发，避免普通复位后保留的闹钟因 EXTI 配置丢失而失效。其他模块不得占用 DR0，后续 NTP 校时仍需单独实现。

2026-10-19 用户确认屏幕仍接原板接口，MOSI 为 PC3，且串口和其他功能正常。此前 CubeMX 再生成将 MOSI 改为 PB15，造成固件输出与实际接线不符；现将 `.ioc` 和生成的 SPI2 配置统一回上表的 PC3/PC5，并保留已恢复的 `BUSY` 标签。后续再生成时须核对 PC3 AF5、PB10 SCK、PC5 BUSY、SPI2 分频 32、RTC 初始化保护、FreeRTOS 入口及 Keil 分组。USART2 中断入口由 Core 唯一定义，平台保留接收和错误回调。引脚修复后的实机刷新仍待验证。

## 任务与内存

`app/display` 创建 normal 优先级显示任务，使用静态任务控制块和 **2048 字节静态栈**。创建过程不消耗 FreeRTOS 堆，`configTOTAL_HEAP_SIZE` 仍为 3000 字节。任务启动成功不代表设备初始化或后续刷新成功，状态通过 `display_get_last_status()` 获取。

控制器原生 RAM 为 128×296，GUI 横向视图为 296×128。生产路径使用一个 9472 字节静态 2bpp 帧缓冲；互斥的黑白诊断/演示复用其前 4736 字节。驱动保留自身背景缓存。最终占用以当前 Keil 链接结果为准，2048 字节显示栈及其他任务栈裕量仍需目标高水位检查。

传输失败保留内存模式并取最新快照重绘，最多连续尝试三次，失败间隔一秒；成功提交后重置重试预算。耗尽后挂起显示任务，其他任务继续。RTC 故障只进入数据/错误页，不作为 EPD 传输错误。休眠失败保留已经提交的画面，下一帧重新复位。自动重新唤醒尚未实现。

## 默认刷新策略与可选演示

Keil 编译宏默认为 `EPD_VENDOR_DEMO_MODE=0`，直接进入正常 RTC 时钟。导入头文件自身的兜底值仍为模式 1，因此其他构建入口必须显式设置该宏。

正常模式为四灰阶：首次、分钟变化、故障集合或持久化格式变化时全刷。每帧执行原厂灰阶复位/初始化、两平面发送和 C7 激活，BUSY 成功结束后提交，随后休眠。显示任务每 200ms 检查快照；RTC 由 defaultTask 每秒读取。刷新中发生的变化合并到下一份最新快照；不显示秒。120 次清理规则仍属于驱动的黑白快刷/局刷能力，不用于生产四灰阶时钟。界面和接口详见 `clock_gray4_ui.md`。

| 宏值 | 参考枚举 | 内容 |
| :---: | :--- | :--- |
| 0 | `EPD_VENDOR_DEMO_OFF` | 正常 RTC 时钟 |
| 1 | `EPD_VENDOR_DEMO_FULL` | 完整原厂演示（含黑白、快刷、灰阶、局刷和 GUI） |
| 2 | `EPD_VENDOR_DEMO_GRAY4` | 原厂 4 灰阶演示 |
| 3 | `EPD_VENDOR_DEMO_PARTIAL_TIME` | 原厂局刷时间演示 |
| 4 | `EPD_VENDOR_DEMO_PARTIAL_FULL` | 原厂局刷/全刷演示 |
| 5 | `EPD_VENDOR_DEMO_ROTATE_180` | 180 度图像演示 |
| 6 | `EPD_VENDOR_DEMO_GUI_342` | 保留参考 GUI_342 演示路径 |

原厂演示执行完后进入四灰阶生产时钟，每次业务刷新重新初始化灰阶。保留的黑白 GUI、方向图和强制全刷诊断宏默认关闭，与原厂演示模式互斥。演示只用于联调，默认业务不依赖演示执行。

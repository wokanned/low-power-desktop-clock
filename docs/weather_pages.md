# 大字天气页（STM32 本地实现）

当前源码的已知缺陷、与用户已确认但尚未实现的行为差异，见[代码与需求差距](current_code_gaps.md)。本文不将待修复项写成已完成。

文档核对日期：2026-11-04；模块接入日期：2026-11-02。本模块为 `app/epd_weather_pages.*`，接收已校验、已固定读租约的
`weather_feed_batch_t`，绘制 296×128 黑白原生画面。控制器、帧缓冲、全局 Paint
和刷新仍由 displayTask 独占，绘制器不调用 HAL、RTOS 或堆分配。新WDATA页面的内容或时间快照变化由显示编排全刷，不套用旧天气页的分钟时间窗口局刷。

## 页面与单位

- 实况：城市、UPD 时间、天气图标和英文名称、大温度、最高~最低、RH、Bft。
  温标随实际数字宽度紧邻；没有 Bft 时保持旧风速的 m/s 语义。
- 三日：三列、天气、最高~最低和降水概率；按可信 RTC 当天及随后两天选列，
  缺失日期/概率显示 N/A。没有可信日期时显示批次实际星期，不声称首条为 TODAY。
- 数值：三列两行 FEELS、UV、AQI-CN、RAIN 1h、PRESS、VIS。有效位缺失时
  显示 N/A；单位分别为 °C、无量纲、中国 AQI、mm、hPa、km。
- 普通天气页底部显示预警类型、等级、数量、最近查询时间；失败/未知/成功无预警/
  解除分别显示，离线保留最近成功时间。天气缓存过期时页头显示 STALE。
- 预警概览用大英文类型、等级和有效截止时间。没有截止时间显示 --:--。官方完整title保留在批次中并校验，所有页面均不增加完整标题显示；正文、指南和来源仍保留。
- 正文和防御指南每屏两行，中文 26×26 点阵。来源机构独立分页，附完整发布和
  截止时间；缺失时间显示 UNKNOWN。

实况天气码继续沿用旧 WEATHER 定义（0～13）；8/9/10 为小/中/大雪，11 为雨夹雪，
12 为雾，13 为霾。不会把旧风速直接当风力。

## 字体与字形

小英文使用 Terminus 原生 14/16px，较大英文使用 20/24/32px 粗体；大预警类型
在容得下时使用 32px 的整数二倍放大。字体原始 BDF 和许可放在
`resources/weather_fonts/`，派生位图由 `tools/generate_weather_pages_assets.py`
生成。数字为 Cascadia Mono 的 24/54px 纯 1-bit 派生位图，完整嵌入许可和源文件
SHA-256 同目录保留；不复制 Windows TTF，也不依赖商业 YaHei/Bahnschrift 字库。
固件正式显示仍只有黑白；gray4 入口仅将同一画面的黑白映射为 0/3 兼容旧测试。

任意中文通过 WDATA 同批字形池提供。每字为 Unicode 码点加 26×26 连续打包 MSB
优先的 85 字节 bitmap，1 为黑色，末 4 bit 为 0；最多 128 个不同非 ASCII 字符。
发送端须使用有相应分发许可的字形来源。字形与正文一起接受事务完整性检查并发布；
没有偷偷用小字形子集替代任意中文。协议层应拒绝缺字或超过池容量的批次，不截掉正文
假装成功；渲染器仍保留空框作为异常输入的防御回退。字形只存 RAM，不访问外部 Flash。

## 自动分页与资源归属

UTF-8 按码点遍历，不在多字节中间断行；一行最多 272px，中文 26px、ASCII 13px。
优先在空格和句读后断开，避免闭合标点孤立在下一行开头，显式换行保留。没有语义断点
时按完整码点断行；这是有界的标点/分句规则，不是自然语言语义解析。正文、指南和来源
各自分页；空正文和空指南跳过，来源即使为空仍保留时间页。
`epd_weather_pages_text_count()` 返回三部分总页数。

调用方用 `weather_feed_acquire(revision, &lease)` 固定当前批次后才绘制；每条返回路径
释放租约，不能把它持有到 SPI/BUSY 等待之后。绘制器不复制整批正文或字形，不创建
帧大小的栈数组。协议可在绘制过程中收集另一份候选数据，不能覆写仍被读取的槽。

## 本地主机验证

运行 `tests/run_weather_pages_host.ps1`：真实 C 绘制器覆盖六种页面、负数/不同位数
温度、全部预警类型和等级、缺失字段、缓存过期、Bft/m/s、最大正文与指南、UTF-8
和非 BMP 动态字形、缓冲区边界，并逐像素比较 BW 与 gray4。生成的 PGM 位于
`build/weather-pages-host/`。这些图像属于 C 渲染结果；预警样例英文和测试字形
不表示已连接真实天气接口，不证明实屏光学效果、串口传输或字形来源授权已验收。

## 已确认保留的规则

- 默认AUTO，暂时接受先晃一下再连接；不增加串口自动唤醒。清醒窗口先取得POWER HOLD应答，再执行控制台/维护，完成后POWER AUTO。
- 有WDATA时CLOCK180秒→LIVE60秒→FORECAST60秒→DATA60秒；无WDATA为两页各180秒。手动阅读页60秒回时钟；自动重要预警60秒回原页。
- important由发送端明确指定；新增/变化/生效才自动显示，无声音；多条优先级遵循B5目标。概览和详情都不增加完整title显示，正文/指南/来源保留。
- 仅持久化时制与旧FORECAST；WDATA、预警、页面、同步年龄和POWER模式不保存。复位回时钟页/AUTO；RTC备份域保时独立于文件持久化。
- 保留WIFI标签，其含义是最近成功同步的整小时，不表示真实网络连接。
- FS FORMAT只清文件分区和RAM预报，保留时制与旧实况，不作为恢复出厂。
- 保留原型故障策略：业务故障可覆盖ERRORS；DBG TX只诊断；显示失败有限重试后挂起；动作源失败保持清醒重试，时钟恢复失败需复位。
- 四键浏览与按键唤醒后续已接入，见[四键说明](buttons.md)，待实板验收。自动联网/NTP、环境与电量、闹钟蜂鸣器、分域断电等继续列后续。

1. 记录板号、供电及镜像哈希，经授权烧录后先在HOLD确认串口/屏幕/RTC正常。文件系统未格式化时停止并另行处理，不自动格式化。

3. 在动作清醒窗口保持AUTO完成文件、预报或维护退出，之后停止发送命令。窗口结束后确认STORAGE位及时解除，并结合电流波形/睡眠统计观察再次睡眠；事务在途与Flash仍忙时不得进入STOP2。普通HOLD→维护→AUTO不能替代该场景。
4. `FS MKDIR /forecast.bin`应被拒绝，普通目录与FORECAST保存可用。已有异常目录只报错，不删除它，不格式化其他文件。
5. 在旧帧BUSY期间提交重要预警，收到COMMIT成功后立即PAGE，确认该旧事件不夺回页面；随后新增预警仍按规则显示。另用两条同时生效、等级不同的预警并反转顺序，确认选择最高优先级，同级选较小索引。
6. 记录原始串口/显示/电流证据、失败与重试、各任务栈高水位。主机或软件计数通过不能替代实际睡眠与设备时序验收。

7. 备份域失电后检查“时间未同步”、TIME?拒绝占位时间、TIME/TIME2授时成功及普通复位保时。升级旧固件后先授时一次。
8. 覆盖WDATA三小时边界、NOW NA、当天/异城/缺失预报及跨日。预警期间提交OFFLINE，随后以业务故障覆盖超过60秒，恢复后检查完整补显。覆盖期间分别到期和手动确认，检查事件结束。

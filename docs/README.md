## 串口联调先读这些

| 需要做的事 | 文档 | 主要内容 |
| --- | --- | --- |
| 发送天气并显示 | [天气协议](weather_protocol.md) | UTF-8、九字段、天气／风向编码、有效天气自动切页、三分钟轮换和三小时过期 |
| 从上位机或 ESP32 校时 | [校时协议](time_protocol.md) | USART2 北京时间 TIME 命令、异步应答、RTC 写入与失败恢复 |
| 上传下载图片、文字等文件 | [文件系统与维护工具](filesystem.md) | littlefs分区、FS命令、Python工具、CRC与断电恢复边界 |
| 查看结果、改12/24小时制或查故障 | [调试控制台](debug_console.md) | JustFloat 与文本模式切换、FORMAT、ERRORS、WEATHER、PAGE、TIME |
| 确认目前完成到哪里 | [技术方案与当前进度](totalPLAN.md#当前开发状态2026-10-27) | 已实现功能、默认上电行为、构建状态和下一步 |

USART2 使用 H10，115200、8N1、3.3V TTL。默认输出二进制遥测；想看文本应答，应先进入控制台。板载 ESP32 的 USART1 与此调试口是两个独立入口。

USART2 使用 H10，115200、8N1、3.3V TTL。默认 AUTO 不持续遥测；在启动/动作清醒窗口先取得 `OK POWER HOLD`，再进入控制台获取文本应答。HOLD 且 CONSOLE OFF 时才持续遥测。板载 ESP32 的 USART1 与此调试口是两个独立入口。

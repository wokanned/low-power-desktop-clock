USART2 保持 115200、8N1、PA2/PA3，TX 为 DMA1 Channel7 / Request2 普通模式，两个 IRQ 均为优先级5。
`.ioc` 和4个 Core 文件由隔离 CubeMX 6.18.1 / STM32Cube FW L4 V1.18.2 生成，未覆盖其他生成文件；
生成日志、命令和同步文件哈希见 `build/usart2-tx-dma-cubemx/result.md`、`synchronized-hashes.json`。
重新生成时仍需核对 USER CODE、DMA句柄关联、初始化顺序、IRQ入口和Keil分组。

发送接口保持同步返回，以独立静态信号量等待最后一字节的 UART TC，等待参数为15 ms；等待期间让出CPU。
失败时在短临界区中止TX，阻止DMA完成与中止过程交错，不重放部分数据。纯DMA错误不清空RX缓冲，
RX错误不提前结束TX等待；TX故障继续仅影响完整诊断，不触发屏幕刷新。15 ms参数不代表实机往返延迟上限。

本轮四组debug测试、clock runtime及BW/gray4各36场景显示集成全部通过，原始日志为
`build/usart2-tx-dma-20261028/debug-host.log`、`clock-runtime.log`、`clock-display.log`。
UART新增用例覆盖提前完成、无回调超时、启动BUSY/ERROR、DMA错误后迟到TC、失败后再发送、RX并发、
接收恢复、错误UART回调、非法上下文、防重入，以及启动/中止临界区和等待时让出CPU的契约。
这些主机桩和链接结果不证明实际DMA中断时序、物理串口吞吐或板上CPU负载。
